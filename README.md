# IceWatch

Интерактивный дашборд ледовой обстановки в северных морях России. Проект
повторяет архитектурный подход SteppeMonitor / Desertification: статический
интерфейс Next.js, Leaflet-карта и отдельный браузерный модуль, который напрямую
запрашивает спутниковые сцены и статистику.

## Что работает

- поиск реальных Sentinel-1 RTC сцен в Microsoft Planetary Computer STAC;
- общая дневная мозаика всех доступных двухполяризационных SAR-сцен VV/VH и
  HH/HV вдоль северного побережья России, независимо от выбранного моря;
- широкозональные суточные мозаики NOAA-20 / VIIRS и Terra / MODIS из NASA
  GIBS с выбором источника в верхней панели;
- всплывающая информация о SAR-сцене только при наведении, без постоянных
  подписей поверх снимков;
- переключение слоёв интенсивности, ледового покрова, структуры и опасности;
- согласованные шкалы: выражение, диапазон и цветовая карта слоя одновременно
  используются при подготовке PNG и построении легенды;
- расчёт зональной статистики через облачный Data API;
- предварительная SAR-классификация открытой воды, молодого, однолетнего и
  деформированного льда;
- временной ряд по доступным спутниковым проходам;
- выбор доступного спутникового прохода ползунком под картой; выбор акватории
  меняет только фокус карты и зону расчёта показателей;
- управляемое окно SAR-мозаики за 1, 3 или 7 суток (по умолчанию 3 суток),
  позволяющее расширить покрытие реальными соседними проходами;
- адаптивный интерфейс в светлой дизайн-системе MTS Web Services.
- демонстрационное наполнение будущих разделов сравнения, статистики,
  маршрутов, выгрузок и оповещений с явной маркировкой «Демо».

Исходные COG-снимки не скачиваются и не сохраняются на компьютере или сервере
приложения. Браузер получает только результаты поиска, агрегированную статистику,
подготовленные PNG-превью и тайлы NASA GIBS из облачных API.

## Важно

Классификация и индекс навигационной опасности являются исследовательской
эвристикой на основе обратного рассеяния VV/VH. Они не заменяют официальные
ледовые карты, гидрометеорологический прогноз и решения капитана.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
pnpm install
pnpm run dev
```

## Публичная демонстрация

GitHub Pages автоматически собирается из ветки `main`:

<https://ulaymi.github.io/icewatch-arctic/>

Для локальной проверки статического варианта:

```bash
pnpm run build:pages
```

## Источники

- Copernicus Sentinel-1 SAR;
- Microsoft Planetary Computer: коллекция `sentinel-1-rtc`, STAC и Data API;
- NASA GIBS: NOAA-20 / VIIRS и Terra / MODIS Corrected Reflectance True Color;
- OpenStreetMap / CARTO для базовой карты.

## Технологии

Next.js, React, TypeScript, Leaflet, vinext и Cloudflare Workers-совместимая
сборка.
